# T-056 — Apply Rate Limiting to Authentication Login Endpoint

**Source finding:** AUDIT_REPORT.md §CTO-04 | Severity: P1 | Class: MISSING  
**Assigned tier:** SENIOR  
**Effort estimate:** 1h | **Sequence:** independent  

## WHAT
In `src/server/app.ts`, attach rate limiting middleware to `/api/auth/login` and `/api/auth/verify`. Set a restrictive threshold (e.g. max 10 requests per minute per IP for `/api/auth/login`) using the existing PostgreSQL-backed `createRateLimiter` utility to protect against email enumeration, email flooding, and third-party quota exhaustion.

## WHY
`/api/auth/login` is currently completely unthrottled. Malicious actors or scripts can trigger infinite magic link requests to arbitrary target emails, incurring Resend costs and risking domain reputation penalties.

## SCOPE — FILES
IN:
- `src/server/app.ts`
- `tests/health.test.ts` (or `tests/auth.test.ts`)

OUT:
- `src/server/auth.ts` (router logic remains intact)
- `src/db/schema.sql` (`rate_limits` table is already implemented)

## ACCEPTANCE CRITERIA (testable, binary)
- [ ] AC1: `/api/auth/login` is protected by `createRateLimiter({ windowMs: 60000, max: 10, message: 'Too many login attempts, please try again in 1 minute.' })`.
- [ ] AC2: Repeated requests exceeding 10 within 1 minute from the same IP return HTTP 429 with standard `Retry-After` header when rate limiting is active.
- [ ] AC3: `/api/auth/verify` is protected by rate limiting to prevent token brute-forcing.
- [ ] AC4: Rate limiter test passes verifying the 429 response when simulated under rate-limiting conditions.

## TEST PLAN
Run: `bun run test tests/health.test.ts tests/auth.test.ts`  
Expected output: All tests pass, including rate-limiting verification.

## CONSTRAINTS
- Use existing `createRateLimiter` function in `src/server/app.ts`.
- Respect `x-test-rate-limit` header behavior during automated test suites.

## ROLLBACK
`git checkout HEAD -- src/server/app.ts`

## BLOCKED PROTOCOL
If `createRateLimiter` is unable to distinguish auth routes: STOP, report issue, status → BLOCKED.
