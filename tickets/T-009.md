# T-009 — Centralized Source Registry & Capability Enforcement

**Source finding:** User Spec §5, §6, §7 | Severity: P0 | Class: CORE_ARCHITECTURE  
**Assigned tier:** SENIOR  
**Effort estimate:** 4h | **Sequence:** P0

## WHAT
Implement the centralized, pre-validated authoritative source registry containing all 26 official sources with friendly display codes (`GEO-ONT-MUN`, `GEO-SGC21`, `DEM-CEN21`, `POP-CSD-EST`, `POP-CSD-PROJ`, `DEM-ETHNIC-AGE`, `DEM-VM-INCOME-CSD`, `DEM-VM-LABOUR-CSD`, `BUS-CNT-CSD`, `BUS-CNT-NONEMP`, `TAX-NAICS22`, `TAX-NOC21`, `LAB-CMA`, `LAB-WAGE`, `SPEND-SHS`, `WEALTH-SFS`, `RENT-CMHC`, `PROP-MULTI-OWNER`, `PROP-OWNER-FAMILY`, `FUEL-RETAIL`, `MUNI-FIR`, `MUNI-BUDGET-CURRENT`, `MUNI-OFFICIAL-PLAN`, `CRE-LISTINGS`, `CRE-MARKET`, `BIZ-OSM`, `BIZ-GOOGLE`, `BIZ-YELP`).
Implement database-level capability enforcement declaring what each source CAN and CANNOT provide, and enforce explicit classification of every analytical observation as `OBSERVED`, `BENCHMARK`, `DERIVED`, or `MODELED`.

## WHY
Prevents hardcoded table IDs, URLs, and scattered metadata. Disallows illegitimate substitutions (e.g. using provincial benchmarks as municipal facts or OSM as verified active business counts).

## SCOPE — FILES
IN:
- `src/db/schema.sql` (Add `metric_classification` column and check constraint to `observations` and `metrics_definitions`)
- `src/ingestion/registry.ts` (Populate all 26 sources with friendly codes, capabilities, refresh policies)
- `src/server/routes.ts` (Expose `/api/sources` and `/api/sources/:code` endpoints)
- `tests/source-registry.test.ts` (New test suite for capabilities and classifications)

## ACCEPTANCE CRITERIA
- [ ] AC1: All 26 sources are registered with friendly code, official publisher, catalogue number, reference period, and official URL.
- [ ] AC2: Source capability registry specifies what each dataset CAN and CANNOT provide.
- [ ] AC3: Every analytical metric observation stores `metric_classification` (`OBSERVED`, `BENCHMARK`, `DERIVED`, `MODELED`).
- [ ] AC4: `GET /api/sources` returns the full registry with friendly codes and capability matrices.
- [ ] AC5: Tests verify capability check rejection when requesting unauthorized attributes.
