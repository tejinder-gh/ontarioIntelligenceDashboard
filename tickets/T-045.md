# T-045 — Fix server bind address to loopback

**Source finding:** AUDIT_REPORT.md §2 | Severity: P1 | Class: BROKEN
**Assigned tier:** INTERMEDIATE
**Effort estimate:** 1h | **Sequence:** independent

## WHAT
Change the server bind address in the Express listener from `::` to `127.0.0.1` to ensure the Node server doesn't expose internal APIs to the public internet by default, fixing local smoke tests.

## WHY
Binding to all interfaces (::) was blocked by local security checks and exposes unauthenticated endpoints if not running behind a reverse proxy.

## SCOPE — FILES
IN:  `src/server/index.ts`
OUT: `src/server/app.ts` (Application logic remains untouched)

## ACCEPTANCE CRITERIA (testable, binary)
- [ ] AC1: `src/server/index.ts` calls `app.listen` with `127.0.0.1` or explicitly checks `process.env.HOST`.
- [ ] AC2: `bun run server` starts successfully and can be curled via `http://127.0.0.1:3001/api/meta/freshness`.

## TEST PLAN
Run `bun run server` locally, confirm logs say "running on 127.0.0.1". 

## CONSTRAINTS
- Do not add new dependencies.
- Retain existing graceful shutdown logic.

## ROLLBACK
Revert commit on `src/server/index.ts`.

## BLOCKED PROTOCOL
If the environment relies on `::` for Docker networking without an override, STOP and report.
