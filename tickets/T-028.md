# T-028 — Sanitize database error messages in venture capital routes

**Source finding:** AUDIT_REPORT.md §CTO-3 | Severity: P1 | Class: BROKEN  
**Assigned tier:** INTERMEDIATE  
**Effort estimate:** 1h | **Sequence:** independent

## WHAT
Standardizes error handling across all 9 endpoints in `src/server/vc-routes.ts`. Currently, lines 13, 30, 45, 61, 72, 89, 101, 112, and 123 respond with `res.status(500).json({ success: false, error: err.message })`. This leaks internal PostgreSQL error messages, column names, and SQL syntax to the client. All 500 error responses must be sanitized to `{ success: false, error: 'Internal server error while querying venture capital telemetry' }` while logging `console.error` on the server.

## WHY
Prevents database reconnaissance and information leakage in production environments.
