# T-026 — Fix regional venture capital SQL predicate and distance calculation

**Source finding:** AUDIT_REPORT.md §CTO-1 | Severity: P0 | Class: BROKEN  
**Assigned tier:** SENIOR  
**Effort estimate:** 2h | **Sequence:** independent (first in sprint)

## WHAT
Remediates the regional venture capital SQL query in `vcIntelligenceService.getRegionalVCSummary`. The current query uses `WHERE l.city ILIKE ${'%' + cleanCity + '%'} OR l.state_province = 'ON'`, which causes any queried Ontario municipality (such as Burlington, Barrie, or Moosonee) to return the aggregate data for the entire province (22 companies and $1.99B capital raised). The query must strictly filter by the specific city (`WHERE l.city ILIKE ${'%' + cleanCity + '%'} AND (l.state_province = 'ON' OR l.country_code = 'CA')`). When a municipality has 0 local venture-backed companies, it must return `ventureBackedCompanies: 0`, `capitalRaisedUsd: 0`, `roundCount: 0`, and provide nearby hub distances.

## WHY
Eliminates a critical P0 data hallucination that destroys user trust and violates the platform's core zero-guesswork, zero-substitution principle.
