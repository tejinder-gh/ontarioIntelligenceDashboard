# T-058 — Generate Programmatic Sitemap for All 444 Municipalities

**Source finding:** AUDIT_REPORT.md §CMO-02 | Severity: P2 | Class: MISSING  
**Assigned tier:** INTERMEDIATE  
**Effort estimate:** 2h | **Sequence:** independent  

## WHAT
Create a script `scripts/generate-sitemap.ts` that queries the `geographies` table for all 444 Ontario municipalities and generates an exhaustive, valid `public/sitemap.xml` incorporating canonical deep-link URLs (e.g. `/city/Burlington/overview`, `/city/Burlington/opportunity`, etc.). Add a package script `"sitemap:build": "bun run scripts/generate-sitemap.ts"` and execute it to populate `public/sitemap.xml`.

## WHY
Currently, `public/sitemap.xml` only lists 7 municipalities, leaving 437 Ontario municipalities completely omitted from search engine indexing, forfeiting thousands of monthly organic visits for high-intent long-tail keywords.

## SCOPE — FILES
IN:
- `scripts/generate-sitemap.ts`
- `public/sitemap.xml`
- `package.json`

OUT:
- `src/server/*` (server routes are already configured for static assets)
- `src/client/*` (client UI is out of scope)

## ACCEPTANCE CRITERIA (testable, binary)
- [ ] AC1: `scripts/generate-sitemap.ts` queries all active municipalities from `geographies` where `type = 'CSD'` or `population_2021 > 0`.
- [ ] AC2: Outputs valid XML compliant with standard `http://www.sitemaps.org/schemas/sitemap/0.9` schema.
- [ ] AC3: `public/sitemap.xml` contains all 444 Ontario municipalities with appropriate `<loc>`, `<changefreq>`, and `<priority>` tags.
- [ ] AC4: `package.json` contains `"sitemap:build"` script.
- [ ] AC5: Script executes without error via `bun run sitemap:build`.

## TEST PLAN
Run: `bun run sitemap:build && wc -l public/sitemap.xml`  
Expected output: Script executes successfully and `public/sitemap.xml` contains entries for all 444 municipalities (>1,000 lines of XML).

## CONSTRAINTS
- XML format must be well-formed and valid for search engine crawlers.
- Use existing `sql` connection from `src/db/index.ts`.

## ROLLBACK
`git checkout HEAD -- public/sitemap.xml package.json && rm -f scripts/generate-sitemap.ts`

## BLOCKED PROTOCOL
If `geographies` table is inaccessible: STOP, report issue, status → BLOCKED.
