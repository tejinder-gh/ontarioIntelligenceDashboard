# T-033 — Sanitize 45 internal error handlers in src/server/routes.ts

**Source finding:** AUDIT_REPORT.md §CTO-14 | Severity: P1 | Class: BROKEN / SECURITY  
**Assigned tier:** INTERMEDIATE  
**Effort estimate:** 2h | **Sequence:** 1

## WHAT
In `src/server/routes.ts`, replace 45 instances of `res.status(500).json({ error: err.message })` with sanitized error handling:
1. Log detailed error to `console.error('[API Error]', err)` on the server.
2. Return a sanitized, generic error payload to the client: `res.status(500).json({ success: false, error: 'Internal server error processing request' })`.

## WHY
Prevents PostgreSQL table names, query syntax, and constraint violation identifiers from leaking to untrusted HTTP clients.
