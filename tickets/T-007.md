# T-007 — Implement internationalization scaffolding and locale-aware formatters

**Source finding:** User Amendment #4 | Severity: P2 | Class: MISSING  
**Assigned tier:** INTERMEDIATE  
**Effort estimate:** 3h | **Sequence:** independent

## WHAT
Create an internationalization (i18n) scaffolding module with central locale-aware formatters for Canadian English (`en-CA`) and Canadian French (`fr-CA` readiness). Build standardized utilities for: currency formatting (e.g. `$116,000` vs `116 000 $`), number formatting (comma vs space thousand separator), percentage formatting, and date formatting. Establish a structured translation dictionary resource format (`src/i18n/locales/en-CA.json` and `fr-CA.json`) and migrate key shell UI tokens and table headers to use the localization helper.

## WHY
Prepares the platform architecture for bilingual public-sector procurement (Ontario government and bilingual municipalities like Ottawa and Sudbury) without wasting hundreds of hours translating entire application copy before customer demand validates it.

IN:
- `src/client/utils/formatters.ts`

- `src/client/i18n/locales/en-CA.json`
- `src/client/i18n/locales/fr-CA.json`
- `src/client/components/Navbar.tsx`
- `src/client/components/Sidebar.tsx`
OUT:
- Complex chart components (Recharts internal text)
- Deep analysis views copy
