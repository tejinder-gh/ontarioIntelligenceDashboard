# T-052 — Implement Stripe Webhook Verification and Order Fulfillment

**Source finding:** AUDIT_REPORT.md §CTO-01 | Severity: P0 | Class: BROKEN  
**Assigned tier:** SENIOR  
**Effort estimate:** 3h | **Sequence:** independent (first in order)  

## WHAT
Replace the 5-line stub in `src/server/stripe-webhook.ts` with production Stripe webhook verification and order fulfillment. The handler will verify incoming `stripe-signature` headers using `stripe.webhooks.constructEvent`, listen for `checkout.session.completed`, record the transaction into the `dossier_orders` table (with `customer_email`, `city_id`, `category_id`, `amount_total_cad`, `payment_status`), trigger `sendDossierEmail` via Resend, and update `fulfilled_at`.

## WHY
Currently, customers paying $199 on Stripe trigger an empty stub returning `{ received: true }`. The order is never recorded, the digital dossier is never delivered, and the purchase record is absent from the user's account, creating 100% chargeback risk and revenue loss ($7,960/mo).
