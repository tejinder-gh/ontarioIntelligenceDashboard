# T-032 — Wire Stripe checkout intent and downloadable PDF stub for Feasibility Dossier

**Source finding:** AUDIT_REPORT.md §CFO-1 | Severity: P0 | Class: MISSING  
**Assigned tier:** SENIOR  
**Effort estimate:** 4h | **Sequence:** after T-026

## WHAT
Remediates the simulated checkout modal in `src/client/components/FeasibilityDossierModal.tsx`. Currently, clicking "Proceed to Checkout" logs a telemetry event to `/api/alerts/events` and displays a fake "Order Confirmed!" message with no actual payment or document delivery. This change:
1. Implements a server-side endpoint `POST /api/checkout/dossier` in `src/server/routes.ts` that validates checkout payload (email, cityId, categoryId) and creates a Stripe Checkout session if `STRIPE_SECRET_KEY` is configured in environment, or returns an explicit test-mode purchase confirmation with instant PDF generation instructions.
2. In `FeasibilityDossierModal.tsx`, replaces the fake confirmation text with genuine fulfillment actions: allows immediate 1-click print-to-PDF export (`window.print()`) styled as a multi-page executive dossier, or redirects to the Stripe Checkout session.
3. Records all genuine purchase intents in an audited ledger table `dossier_orders`.

## WHY
Stops funnel leakage and provides actual commercial fulfillment for users seeking location feasibility dossiers.
