# T-031 — Deploy production marketing assets and metadata directives

**Source finding:** AUDIT_REPORT.md §CMO-1 | Severity: P1 | Class: MISSING  
**Assigned tier:** INTERMEDIATE  
**Effort estimate:** 2h | **Sequence:** independent

## WHAT
Deploys critical SEO and social marketing infrastructure to make the platform discoverable and shareable:
1. Replaces the SVG `og:image` reference in `index.html` (`/favicon.svg`) with an authentic 1200x630 PNG social preview card (`/og-image.png`). Major social platforms (Twitter, LinkedIn, Facebook, Slack) reject SVGs for card previews.
2. Adds `public/robots.txt` with standard search engine crawl directives allowing `/` and disallowing internal `/api/` endpoints.
3. Adds `public/sitemap.xml` listing primary municipal intelligence, rankings, and methodology routes.
4. Adds JSON-LD structured data (`schema.org/SoftwareApplication`) to `index.html`.

## WHY
Unblocks social sharing preview cards on LinkedIn and Twitter and enables organic search engine discovery across Ontario municipal search queries.

## SCOPE — FILES
IN:
- `index.html`
- `public/robots.txt`
- `public/sitemap.xml`
- `public/og-image.png`

OUT:
- `src/*` (Application code not modified)

## ACCEPTANCE CRITERIA (testable, binary)
- [ ] AC1: `public/robots.txt` exists and serves valid crawl directives.
- [ ] AC2: `public/sitemap.xml` exists and validates with standard XML schema.
- [ ] AC3: `index.html` specifies `og:image` and `twitter:image` pointing to `/og-image.png`.
- [ ] AC4: `public/og-image.png` exists as a valid PNG image.
- [ ] AC5: `index.html` includes JSON-LD structured data tag.
- [ ] AC6: `npm run build` succeeds and copies assets to `dist/`.

## TEST PLAN
```bash
npm run build
test -f dist/robots.txt
test -f dist/sitemap.xml
test -f dist/og-image.png
grep "og-image.png" dist/index.html
```

## CONSTRAINTS
- Static assets only; zero runtime dependencies.

## ROLLBACK
`git checkout HEAD -- index.html && rm -f public/robots.txt public/sitemap.xml public/og-image.png`.

## BLOCKED PROTOCOL
None anticipated.
