# T-050 — Implement post-checkout success modal UI

**Source finding:** AUDIT_REPORT.md §Phase 3 | Severity: P1 | Class: SUBOPTIMAL
**Assigned tier:** INTERMEDIATE
**Effort estimate:** 1h | **Sequence:** independent

## WHAT
Update the frontend to detect the `?success=true` URL parameter on page load. If present, render a success modal (e.g. `CheckoutSuccessModal.tsx`) that thanks the user and explicitly states "Your Location Feasibility Dossier has been sent to your email."

## WHY
Currently, users are redirected back to the homepage silently. A success modal confirms the transaction and sets delivery expectations.

## SCOPE — FILES
IN: 
- `src/client/App.tsx` or similar root component where URL params can be read.
- `src/client/components/CheckoutSuccessModal.tsx` (NEW)

OUT: 
- `src/server/*` (Backend should not be touched).

## ACCEPTANCE CRITERIA (testable, binary)
- [ ] AC1: A new React component `CheckoutSuccessModal` is created.

- [ ] AC3: The modal explicitly mentions that the dossier has been emailed.
- [ ] AC4: A close button on the modal removes the `?success=true` parameter from the URL using `history.replaceState`.

## TEST PLAN
