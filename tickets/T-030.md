# T-030 — Code-split client SPA bundle using React lazy loading and manual chunks

**Source finding:** AUDIT_REPORT.md §CTO-4 | Severity: P1 | Class: SUBOPTIMAL  
**Assigned tier:** SENIOR  
**Effort estimate:** 3h | **Sequence:** after T-029

## WHAT
Refactors `src/client/App.tsx` and `vite.config.ts` to implement route-level code splitting. Currently, all 17 intelligence views are statically imported at the top of `App.tsx`, producing a single monolithic 1.2 MB uncompressed JavaScript bundle (`dist/assets/index-CQK3RM8M.js`). This change:
1. Replaces static imports of views with dynamic `React.lazy(() => import(...))` wrappers.
2. Wraps view switching in `React.Suspense` with an accessible specular glass loading skeleton.
3. Configures Rollup `manualChunks` in `vite.config.ts` to separate large vendor libraries (`vendor-react`, `vendor-recharts`, `vendor-icons`) from application code.
4. Removes the artificial `chunkSizeWarningLimit: 1500` workaround, ensuring Vite builds without warnings.

## WHY
Reduces initial page load payload from 1,196 kB down to <300 kB, drastically improving Largest Contentful Paint (LCP) and mobile performance across cellular connections.
